Introducción

Las matemáticas son fundamentales en la programación. Este portafolio reúne aplicaciones desarrolladas con HTML, CSS y JavaScript que permiten resolver operaciones matemáticas de forma interactiva y fortalecer la lógica mediante programación.

Objetivos

  • Aplicar operaciones con fracciones.
  • Simplificar resultados usando el MCD.
  • Generar ejercicios matemáticos aleatorios.
  • Calcular áreas y perímetros de figuras geométricas.
  • Fortalecer la lógica mediante programación.
